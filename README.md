# Midnight Fuel (yaa raheem) 🌙🔥

Tirunelveli's ultimate midnight food ordering and delivery web application. Serves hot Arabian Mandi, Dum Biryani, Shawarmas, Crispy Parottas, and Monster Burgers daily from 7:00 PM to 2:00 AM.

## Features

- 📱 **Mobile & Desktop Responsive**: Custom mobile sticky bottom navigation bar and desktop sidebar.
- 🍽️ **Interactive Menu**: Category filtering, veg/non-veg toggle, popularity badges, and price sliders.
- 🛒 **Cart & Checkout**: Real-time item pricing, coupon code discount calculations, and address pin drop.
- 🗺️ **GPS Driver Tracking**: Live map tracking using OpenStreetMap / Leaflet.
- 🔒 **Admin Portal & KDS**: Real-time kitchen order management suite with receipt modal printing.
- ⚡ **Razorpay & COD**: Cash on Delivery and Online Razorpay payment gateway options.

## Tech Stack

- **Frontend**: React 18, TypeScript, Vite, Tailwind CSS, Lucide Icons
- **Backend / DB**: Firebase / Node.js
- **Map**: Leaflet / OpenStreetMap
